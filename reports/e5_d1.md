### 核心发现（以 `onpolicy, k=0, B=4, beta=0.9, t=16` 为例）

1. **均方根版 `C1_pred` 反映了纯噪声幅值稀释后的对齐度，而真实对齐 `C2` 依然很高**：
   - 在 `onpolicy, k=0, B=4, beta=0.9, t=16` 下，信噪比仅为 `SNR_exact = 0.1596 ± 0.0027`。均方根预测值 `C1_pred = 0.3140 ± 0.0061`（满足 $\approx C_2 / \sqrt{1 + 1/\mathrm{SNR}}$，严格落在 $[-1, 1]$ 内），而动量与真实期望梯度 $h_t$ 的余弦高达 **`C2_exact_h = 0.8771 ± 0.0104`**（无偏估计 `C2_hat = 0.9141 ± 0.0167`）。
   - 同时，从 $t=16$ 到 $t=64$ 的真实期望梯度余弦为 **`C3_exact_h(16, 64) = 0.6323 ± 0.0321`**，表明真实梯度方向稳定。
2. **关于 $B=4, t=16$ 时实测 `C1` 为负（`-0.0697 ± 0.0088`）的机制说明（Bandit 特有机理）**：
   - 在本 Bandit 设定的小样本（$B=4$）下，`C1` 之所以为负并低于均方根版 `C1_pred`（`+0.3140`），来自**只剩 KL 项的 batch，属于该 Bandit 模型特有的机制**：
   - 具体而言，Bandit 单批方向为 $g = \Pi[\hat{r}_{\text{batch}} - \lambda(\log p_t - \log p_{\text{ref}})]$。当 $B=4$ 未抽中那 2 个好臂时（奖励项 $\hat{r}_{\text{batch}} = 0$），单批方向退化为纯 KL 拉回项 $g_{\text{zero}} = -\lambda\Pi(\log p_t - \log p_{\text{ref}})$。由于历史动量 $m_{t-1}$ 沿着脱离 $p_{\text{ref}}$ 的方向前进，纯 KL 项与 $m_{t-1}$ 方向几乎完全相反（余弦接近 $-1$），且因为缺少稀疏大项 $r_a/p_a$，其范数 $\|g_{\text{zero}}\|$ 远小于抽中好臂时的 $\|g_{\text{hit}}\|$。
   - 单批余弦 $C_1 = \mathbb{E}[\langle m, g\rangle / (\|m\|\|g\|)]$ 对每个 batch 按 $1/\|g\|$ 归一化，使得这些只剩反向 KL 项的小范数 batch 占据了极大的权重（这也正是 `C1_pred_legacy` 被 $\mathbb{E}[1/\|g\|]$ 放大到 $>1$ 的原因）。而在 LLM 实验（§6.2）中，我们不加 KL 项（$\beta_{\text{KL}}=0$），全 0 奖励组的优势 $A=0$、梯度严格为 $0$，不会产生这种纯 KL 反向小梯度。因此 Bandit 上 $B=4$ 时 `C1 < 0` 属于 Bandit 特有的机制，不能直接等同于 LLM 中的现象。
