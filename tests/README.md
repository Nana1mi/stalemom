# 独立测试（用户提供，禁止修改）

这套测试与实现分开编写，用来交叉验证 `stalemom` 包是否严格符合 `SPEC_E0-E2.md`。
参考公式写在 `conftest.py` 里，故意采用与 SPEC 不同的写法（直接按定义、伪逆、精确枚举、逐步参考轨迹）。

## 运行

```bash
pip install numpy pytest
python -m pytest tests -q
```

需要在项目根目录运行，`stalemom/` 与 `tests/` 同级。

## 覆盖内容

| 文件 | 检查什么 |
|---|---|
| `test_bandit.py` | softmax 数值稳定性、目标与最优值、NPG 闭式（与 F⁺∇J 对比）、梯度（与有限差分对比） |
| `test_estimators.py` | 各估计器公式、B>1 时无批内归一化、IS 无偏与 TIS 偏差闭式（精确枚举）、蒙特卡洛一致性、同步退化、截断率边界 |
| `test_optim.py` | ρ→omb、偏差修正分母（与有理数精确值对比）、EMA 权重、历史年龄、长记忆退化为累计平均 |
| `test_sim.py` | 输出形状、J 与 gap 的一致性、θ 更新与动量递推、滞后与行为策略、确定性轨迹与独立参考实现逐步对比、诊断分解恒等式 |

## 已验证

这套测试已对照一份私下写的参考实现全部通过（87 项），并做过“植入错误”检验：下列 16 种典型错误逐一植入后，每一种都会让至少一项测试失败。

- IS 分母用 p 而不是 q；完整 IS 做了批内归一化
- TIS 不截断；TIS 权重写反成 q/p；去偏符号写反；偏差漏掉投影
- 截断率用 ≥ 而不是 >；KL 项符号写反；NPG 方向没投影；J* 漏乘 λ
- 偏差修正指数差一；EMA 权重写反
- 滞后差一位；行为策略没有滞后；**用旧参数计算梯度（经典异步 SGD 的错误建模）**
- `tis` 模式的分解里把偏差记成 0

测试失败时，应该修实现，不能放宽断言或修改本目录下的文件。
